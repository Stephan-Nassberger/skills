## What it does

Use this skill whenever the user mentions Microsoft Teams in a development context — whether they're building, integrating, configuring, debugging, porting a Slack bot to Teams, or just asking questions. Covers bots, message extensions, embedded web apps, Adaptive Cards, dialogs, SSO, infrastructure, the Teams Developer CLI/SDK, Slack Bolt migration, and general Teams platform queries. If the word "Teams" appears, err on the side of invoking this skill.

This workflow follows the target project's actual version and available tools. It does not grant tenant permissions or deploy a solution merely because the skill is installed.

## When to reach for it

Type `/teams-dev`, or the agent can select it when the task fits. Use its documented product boundary; combine it with Microsoft Learn for current Microsoft API and compatibility evidence.
